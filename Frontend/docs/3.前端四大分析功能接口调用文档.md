# 前端四大分析功能接口调用文档

## 概述

本文档详细描述了前端四大空间分析功能（缓冲区分析、最短路径分析、相交分析、擦除分析）的接口调用方式、数据格式和实现流程。

## 通用配置

### API服务配置
- **配置函数：** `getAnalysisServiceConfig()`
- **默认地址：** `http://localhost:8087/api/v1/spatial-analysis`
- **环境变量配置：**
  - `VITE_ANALYSIS_SERVICE_BASE_URL`: 分析服务基础URL
  - `VITE_ANALYSIS_SERVICE_API_PREFIX`: API前缀路径
  - `VITE_API_TIMEOUT`: 请求超时时间
  - `VITE_API_RETRY_COUNT`: 重试次数
  - `VITE_ANALYSIS_API_KEY`: API密钥（生产环境）
- **超时时间：** 30秒（开发环境），45秒（生产环境）
- **重试次数：** 3次
- **坐标系：** EPSG:4326

### 数据流转过程
1. **数据提取阶段：** 使用`extractGeoJSONFromlayer`函数从OpenLayers图层提取GeoJSON数据
2. **API调用阶段：** 各分析功能调用对应的后端API接口（使用fetch而非axios）
3. **数据接收阶段：** 接收后端返回的FeatureCollection格式数据
4. **图层渲染阶段：** 调用对应的display*Results()函数创建OpenLayers要素并添加到地图
5. **结果保存阶段：** 使用`saveFeaturesAslayer`函数将结果保存为图层
6. **交互显示阶段：** 通过useMapInteraction处理要素点击，使用formatPropertyValue格式化属性值并在弹窗中显示

## 1. 缓冲区分析 (Buffer Analysis)

### 接口信息
- **HTTP方法：** POST
- **接口地址：** `${API_BASE_URL}/buffer`
- **实现文件：** `Frontend/src/composables/useBufferAnalysis.ts`
- **调用位置：** 第202行

### 请求数据格式
```javascript
{
  sourceData: FeatureCollection,  // 源图层数据
  bufferSettings: {
    radius: number,               // 缓冲距离（米）
    semicircleLineSegment: number // 圆弧精度步数
  },
  options: {
    resultlayerName: string       // 结果图层名称
  }
}
```

### 调用示例
```javascript
const API_BASE_URL = getAnalysisServiceConfig().baseUrl
const response = await fetch(`${API_BASE_URL}/buffer`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(requestData)
})
const apiResponse = await response.json()
```

### 功能特点
- 支持点、线、面要素的缓冲区分析
- 可配置缓冲距离和圆弧精度
- 自动处理图层分页加载
- 支持结果保存为图层

## 2. 最短路径分析 (Shortest Path Analysis)

### 接口信息
- **HTTP方法：** POST
- **接口地址：** `${API_BASE_URL}/shortest-path`
- **实现文件：** `Frontend/src/composables/useShortestPathAnalysis.ts`
- **调用位置：** 第582行

### 请求数据格式
```javascript
{
  startPoint: {
    type: 'Point',
    coordinates: [number, number]  // 起点坐标
  },
  endPoint: {
    type: 'Point', 
    coordinates: [number, number]  // 终点坐标
  },
  analysisOptions: {
    units: string,                 // 单位 ('degrees' | 'radians' | 'miles' | 'kilometers')
    resolution: number             // 分辨率
  },
  options: {
    returnGeometry: boolean,
    calculateDistance: boolean,
    calculateDuration: boolean,
    averageSpeed: number
  },
  obstacleData?: FeatureCollection // 可选的障碍物数据
}
```

### 调用示例
```javascript
const API_BASE_URL = getAnalysisServiceConfig().baseUrl
const response = await fetch(`${API_BASE_URL}/shortest-path`, {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(requestData)
})
const apiResponse = await response.json()
```

### 功能特点
- 支持起点和终点选择
- 可配置分析单位和分辨率
- 支持障碍物数据
- 计算距离和持续时间
- 支持结果导出和保存

## 响应数据格式

所有分析接口均返回标准的GeoJSON FeatureCollection格式：

```javascript
{
  type: "FeatureCollection",
  features: [
    {
      type: "Feature",
      geometry: {
        type: "Polygon" | "LineString" | "Point",
        coordinates: [...]
      },
      properties: {
        // 要素属性
      }
    }
  ],
  statistics?: {
    // 统计信息（可选）
  }
}
```

## Agent集成

### 事件监听
前端通过自定义事件监听Agent的分析请求：

```javascript
// 缓冲区分析
window.addEventListener('agent:executeBufferAnalysis', async (e) => {
  const { layerName, radius, unit } = e.detail
  // 执行缓冲区分析
})

// 相交分析
window.addEventListener('agent:executeIntersectionAnalysis', async (e) => {
  const { targetLayerName, maskLayerName } = e.detail
  // 执行相交分析
})

// 擦除分析
window.addEventListener('agent:executeEraseAnalysis', async (e) => {
  const { targetLayerName, eraseLayerName } = e.detail
  // 执行擦除分析
})

// 最短路径分析
window.addEventListener('agent:executeShortestPathAnalysis', async (e) => {
  const { startLayerName, endLayerName, obstacleLayerName } = e.detail
  // 执行最短路径分析
})
```

### 结果反馈
分析完成后，通过自定义事件向Agent反馈结果：

```javascript
const resultEvent = new CustomEvent('agent:analysisResult', {
  detail: {
    success: true,
    analysisType: 'buffer',
    layerName: '缓冲区分析结果',
    featureCount: features.length,
    message: '分析完成'
  }
})
window.dispatchEvent(resultEvent)
```

## 错误处理

### 常见错误类型
1. **图层不存在：** 指定的图层名称未找到
2. **要素为空：** 图层中没有要素数据
3. **API调用失败：** 网络错误或服务器错误
4. **数据格式错误：** 请求数据格式不正确

### 错误处理机制
```javascript
try {
  const response = await fetch(`${API_BASE_URL}/buffer`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(requestData)
  })
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`)
  }
  
  const apiResponse = await response.json()
  // 处理成功响应
} catch (error) {
  console.error('分析执行失败:', error)
  // 显示错误提示
  analysisStore.setAnalysisStatus('分析执行失败: ' + error.message)
}
```

### 结果处理优化
- 使用`saveFeaturesAslayer`函数保存分析结果
- 支持`useLayerExport`导出功能
- 缓存机制减少重复计算

## 扩展说明

### 添加新的分析功能
1. 在`composables`目录下创建对应的composable文件（如`useNewAnalysis.ts`）
2. 在`stores`目录下创建对应的状态管理文件（如`newAnalysisStore.ts`）
3. 实现API调用逻辑（使用fetch而非axios）
4. 添加结果渲染函数（`displayNewAnalysisResults`）
5. 在对应的分析面板组件中集成功能
6. 在Agent中注册对应的事件监听
7. 更新本文档

### 配置修改
- 修改`Frontend/src/api/config.ts`中的API配置
- 更新环境变量设置（`.env`文件）
- 重启前端服务使配置生效

### 状态管理
每个分析功能都有对应的Pinia store：
- `useBufferAnalysisStore` - 缓冲区分析状态
- `useIntersectionAnalysisStore` - 相交分析状态
- `useEraseAnalysisStore` - 擦除分析状态
- `useShortestPathAnalysisStore` - 最短路径分析状态
