# 事件驱动分析机制

## 概述

SuperMap前端应用采用事件驱动架构，通过全局事件系统实现LLM Agent与前端组件的解耦通信。该机制支持智能对话、分析功能执行、结果反馈等完整的数据流转过程。

## 整体架构

### 1. 事件流转层次

```
LLM Agent (后端)
    ↓ 工具调用解析
ChatAssistant.vue (事件分发器)
    ↓ 全局事件分发
useLayerManager.ts (功能执行器)
    ↓ 分析结果反馈
ChatAssistant.vue (结果处理)
    ↓ 隐式消息发送
LLM Agent (智能回应)
```

### 2. 核心组件职责

- **ChatAssistant.vue**：事件监听器，负责接收LLM工具调用并分发事件
- **useLayerManager.ts**：功能执行器，负责监听事件并执行具体功能
- **各分析Composables**：业务逻辑处理器，负责具体分析功能实现
- **Store系统**：状态管理器，负责数据持久化和状态同步

## 数据流转过程

### 1. 用户输入到功能执行

```typescript
// 1. 用户输入处理
const sendMessage = async () => {
  const message = newMessage.value.trim()
  messages.value.push({ id: Date.now(), text: message, sender: 'user' })
  
  // 2. 发送到LLM Agent
  const resp = await fetch(`${apiBase}/agent/tool-chat`, {
    method: 'POST',
    body: JSON.stringify(payload)
  })
  
  // 3. 解析工具调用
  const toolCalls = data?.data?.first_call?.tool_calls || []
  if (toolCalls.length > 0) {
    const call = toolCalls[0]
    const name = call?.name
    
    // 4. 分发对应事件
    if (name === 'execute_buffer_analysis') {
      const ev = new CustomEvent('agent:executeBufferAnalysis', {
        detail: { layerName, radius, unit }
      })
      window.dispatchEvent(ev)
    }
  }
}
```

### 2. 功能执行到结果反馈

```typescript
// 1. 监听分析事件
window.addEventListener('agent:executeBufferAnalysis', async (e) => {
  const { layerName, radius, unit } = e.detail
  
  // 2. 执行分析逻辑
  const { useBufferAnalysis } = await import('@/composables/useBufferAnalysis')
  const bufferAnalysis = useBufferAnalysis()
  await bufferAnalysis.executeBufferAnalysis()
  
  // 3. 获取分析结果
  const bufferResults = bufferAnalysis.lastFeatureCollection.value
  
  // 4. 发送结果反馈事件
  const successEvent = new CustomEvent('agent:bufferAnalysisResult', {
    detail: {
      success: true,
      message: `缓冲区分析完成，图层"${layerName}"，半径${radius}${unit}`,
      layerName,
      radius,
      unit,
      resultCount: bufferResults.features.length
    }
  })
  window.dispatchEvent(successEvent)
})
```

### 3. 结果反馈到LLM回应

```typescript
// 1. 监听结果反馈事件
const handleBufferAnalysisResult = (event: CustomEvent) => {
  const { success, message, layerName, radius, unit, error } = event.detail
  
  // 2. 构造结果消息
  let resultMessage = success 
    ? `缓冲区分析完成：${message}`
    : `缓冲区分析失败：${error || '未知错误'}`
  
  // 3. 添加到聊天记录
  messages.value.push({ 
    id: Date.now(), 
    text: resultMessage, 
    sender: 'system' 
  })
  
  // 4. 隐式发送消息到LLM
  if (success) {
    sendImplicitMessageToLLM(resultMessage)
  }
}

// 5. 隐式消息发送
const sendImplicitMessageToLLM = async (resultMessage: string) => {
  // 构造包含历史记录的完整prompt
  let conversationContext = ''
  if (messages.value.length > 0) {
    conversationContext = '对话历史：\n'
    messages.value.forEach(msg => {
      const role = msg.sender === 'user' ? '用户' : '助手'
      conversationContext += `${role}: ${msg.text}\n`
    })
  }
  
  // 发送到LLM获取智能回应
  const fullPrompt = `${conversationContext}分析结果反馈：${resultMessage}。请根据这个结果给出适当的回应或建议。`
  // ... LLM请求逻辑
}
```

## 事件监听器管理

### 1. 事件注册机制

```typescript
// 防止重复注册
if (!(window as any).__queryResultListenerRegistered) {
  (window as any).__queryResultListenerRegistered = true
  
  // 注册所有事件监听器
  window.addEventListener('agent:queryResult', handleQueryResult)
  window.addEventListener('agent:saveResult', handleSaveResult)
  window.addEventListener('agent:exportResult', handleExportResult)
  window.addEventListener('agent:bufferAnalysisResult', handleBufferAnalysisResult)
  window.addEventListener('agent:intersectionAnalysisResult', handleIntersectionAnalysisResult)
  window.addEventListener('agent:eraseAnalysisResult', handleEraseAnalysisResult)
  window.addEventListener('agent:pathAnalysisResult', handlePathAnalysisResult)
  window.addEventListener('agent:layerVisibilityChanged', handleLayerVisibilityChanged)
}
```

### 2. 事件清理机制

```typescript
// 组件卸载时清理事件监听器
onUnmounted(() => {
  if ((window as any).__queryResultListenerRegistered) {
    window.removeEventListener('agent:queryResult', handleQueryResult)
    window.removeEventListener('agent:saveResult', handleSaveResult)
    window.removeEventListener('agent:exportResult', handleExportResult)
    window.removeEventListener('agent:bufferAnalysisResult', handleBufferAnalysisResult)
    window.removeEventListener('agent:intersectionAnalysisResult', handleIntersectionAnalysisResult)
    window.removeEventListener('agent:eraseAnalysisResult', handleEraseAnalysisResult)
    window.removeEventListener('agent:pathAnalysisResult', handlePathAnalysisResult)
    window.removeEventListener('agent:layerVisibilityChanged', handleLayerVisibilityChanged)
    ;(window as any).__queryResultListenerRegistered = false
  }
})
```

## 导出功能机制

### 1. 导出为图层

```typescript
// 保存分析结果为图层
const saveBufferResultsAsLayer = async (layerName: string) => {
  // 1. 从Store读取结果
  const bufferResults = bufferAnalysis.lastFeatureCollection.value
  
  if (bufferResults && bufferResults.features) {
    // 2. 创建新图层
    const vectorLayer = new VectorLayer({
      source: new VectorSource({
        features: format.readFeatures(bufferResults)
      })
    })
    
    // 3. 添加到地图和图层管理器
    mapStore.map.addLayer(vectorLayer)
    mapStore.vectorlayers.push({
      id: `buffer_${Date.now()}`,
      name: layerName,
      layer: vectorLayer,
      visible: true,
      type: 'vector',
      source: 'analysis'
    })
  }
}
```

### 2. 导出为JSON

```typescript
// 导出分析结果为JSON文件
const exportBufferResultsAsJSON = async (fileName: string) => {
  // 1. 从Store读取结果
  const bufferResults = bufferAnalysis.lastFeatureCollection.value
  
  if (bufferResults) {
    // 2. 创建下载文件
    const dataStr = JSON.stringify(bufferResults, null, 2)
    const dataBlob = new Blob([dataStr], { type: 'application/json' })
    const url = URL.createObjectURL(dataBlob)
    
    // 3. 触发下载
    const link = document.createElement('a')
    link.href = url
    link.download = `${fileName}.json`
    link.click()
    
    URL.revokeObjectURL(url)
  }
}
```

## 总结

SuperMap前端的事件驱动机制通过全局事件系统实现了LLM Agent与前端组件的解耦通信，支持完整的用户交互流程：用户输入 → LLM处理 → 工具调用 → 事件分发 → 功能执行 → 结果反馈 → 智能回应。该机制确保了系统的可扩展性、可维护性和用户体验的一致性。
