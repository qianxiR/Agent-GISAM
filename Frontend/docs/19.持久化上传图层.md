# 持久化上传图层功能文档

## 概述

持久化上传图层功能是管理分析平台的核心特性之一，它允许用户上传的GeoJSON图层数据在页面刷新、模式切换或组件重新加载后仍然保持可见状态。该功能通过多层存储机制和智能的图层管理策略，确保了用户体验的连续性和数据的一致性。

## 功能架构

### 1. 存储层次结构

```
用户上传的图层数据
    ↓
layerDataStore (属性数据存储)
    ↓
mapStore.vectorlayers (图层管理列表)
    ↓
OpenLayers 地图实例 (可视化渲染)
```

### 2. 核心组件

#### 2.1 状态管理组件
- **`layerDataStore`**: 存储图层的属性数据，用于要素查询和信息显示
- **`mapStore`**: 管理图层列表和地图实例，负责图层的可见性控制
- **`modeStateStore`**: 保存和恢复不同模式下的图层状态

#### 2.2 图层管理组件
- **`useLayerManager`**: 提供图层上传、删除、导出等核心功能
- **`useMonitoringDataLayers`**: 管理监测点图层的加载和样式
- **`useYangtzeWaterLayers`**: 管理长江水系图层的加载和样式

    })
  }
}

## 数据流转机制

### 1. 图层数据流转过程

```
用户上传GeoJSON文件
    ↓
解析GeoJSON数据
    ↓
创建OpenLayers要素
    ↓

    ↓

    ↓
添加到OpenLayers地图 (可视化显示)
    ↓
保存到localStorage (持久化存储)
```

## 错误处理机制

### 1. 图层加载错误处理

```typescript
const loadLayerWithErrorHandling = async (layerData: any) => {
  try {
    // 尝试加载图层
    await loadLayer(layerData)
  } catch (error) {
    console.error('图层加载失败:', error)
    
    // 错误处理策略
    if (error.name === 'GeoJSONParseError') {
      showErrorMessage('GeoJSON文件格式错误，请检查文件格式')
    } else if (error.name === 'NetworkError') {
      showErrorMessage('网络错误，请检查网络连接')
    } else {
      showErrorMessage('图层加载失败，请重试')
    }
    
    // 清理部分加载的数据
    cleanupPartialLoadedData(layerData)
  }
}
```

const restoreStateWithErrorHandling = () => {

## 最佳实践

### 1. 图层命名规范

- 使用有意义的图层名称，避免重复
- 包含时间戳或版本信息，便于管理
- 使用统一的命名前缀，如 `monitoring_`, `yangtze_`, `user_`

### 2. 属性数据管理

- 确保所有要素都有唯一的ID
- 保留原始GeoJSON属性，同时添加扩展属性
- 定期清理不再使用的属性数据

### 3. 性能优化建议

- 避免同时加载过多图层
- 使用适当的图层层级设置
- 及时清理临时图层和分析结果

### 4. 错误处理建议

- 实现完善的错误处理机制
- 提供用户友好的错误提示
- 记录详细的错误日志用于调试

持久化上传图层功能通过多层存储机制和智能的状态管理，为用户提供了连续、稳定的图层管理体验。该功能不仅支持用户上传的图层数据持久化，还集成了监测点图层和长江水系图层的自动加载，确保了数据的完整性和用户体验的一致性。
